# Raspberry Pi Pico ZOOM G5n MIDI Switcher & Looping System

Raspberry Pi Pico（RP2040）をUSBホストとして動作させ、ZOOM G5nのパッチ切り替えと、自作の5センド/リターン＋1リモート端子のループ制御を完全同期させるプログラマブル・スイッチャーです。

## ⚠️ 重要：ハードウェアの注意事項
* **PC接続厳禁 (5V Output):** 本システムの筐体側USB Type-C端子からは、PicoのUSBホスト機能のために外部から5V電源を供給しています。**絶対にPC、スマートフォン、USB充電器等を直接接続しないでください（回路が破損します）。**

---

## 🛠️ 主な仕様とハードウェア構成

### 筐体・入出力
* **フットスイッチ:** 3個 (NC/NO反転処理・チャタリング対策済み)
* **LED:** 3個 (RGBコンビネーションによる多彩な状態表示)
* **オーディオ・リレー:** 5センド／リターン ＋ 1リモート端子
* **MUTE回路:** フォトモスリレーによるポップノイズレス切り替え
* **USB:** Type-Cメス（PicoネイティブUSBホスト＋手動MIDIエンドポイント奪取）

### 使用GPIOピン配置
* **GPIO 0:** フォトモス（Mute）
* **GPIO 10:** リモート端子
* **GPIO 11〜15:** ループ 5 〜 1
* **GPIO 16:** フットスイッチ 3
* **GPIO 17:** LED 3
* **GPIO 18:** フットスイッチ 2
* **GPIO 19:** LED 2
* **GPIO 20:** フットスイッチ 1
* **GPIO 21:** LED 1

## 🎸 制御ロジックとMIDI連携
* **容量:** バンク数 27 ($3^3$) × パッチ数 5 ＝ 総パッチ数 **135**
* **バンク・パッチ命名規則:** 
  * バンク：`0` 〜 `26`
  * パッチ：`1` 〜 `5`
  * **バンク0:** ZOOM G5nへのMIDI信号送信を行わない（バイパス・マニュアル用）
  * **バンク $n$ のパッチ $m$:** ZOOM G5n側へ `(5n - 5 + m)` 番のパッチ変更指示（CC / Program Change）をType-C端子経由で送信

---

## 🎮 動作モードと操作方法

起動時は自動的に **バンク0 / パッチ1** に移行します。

### 1. 通常モード（パッチモード）
演奏中にパッチを瞬時に切り替えるメインモードです。
* **スイッチ $n$ 単押し:** パッチ $n$ を呼び出し
* **スイッチ 1 & 2 同時押し:** パッチ 4 を呼び出し
* **スイッチ 2 & 3 同時押し:** パッチ 5 を呼び出し
* **スイッチ 1 / 3 長押し:** バンク `-1` / `+1` へ移動（移動先のパッチ1へ飛ぶ）
* **スイッチ 2 長押し:** バンクモードへ移行
* **スイッチ 2 超長押し:** プログラムモード（ループ1設定状態）へ移行

### 2. バンクモード
バンクを大きく移動するためのモードです。
* **スイッチ 1 / 3 単押し:** バンク `-1` / `+1`
* **スイッチ 2 単押し:** パッチモードへ復帰し、そのバンクのパッチ1へジャンプ

### 3. プログラムモード
各パッチにおけるループ（L1〜L5、Remote）のON/OFFを設定するモードです。
* **スイッチ 1 / 3 単押し:** 設定するループを前／次に切り替え（L1 → L2 → L3 → L4 → L5 → Remote の順ループ）
* **スイッチ 2 単押し:** 選択中のループのON/OFFを反転（同時にリレーも即時切り替え）
* **スイッチ 2 長押し:** パッチモードへ復帰（設定内容はフラッシュメモリに自動保存されます）

## 💡 LEDインジケータ・アニメーション仕様
* **パッチ表示:** パッチモード中常時点灯。踏んでいるスイッチに対応するLEDが点灯（例: パッチ4はLED1とLED2が点灯）。
* **バンクアニメーション（三進法表示）:** 
  * パッチモードでバンクを変更した際、一度だけLED1/2/3を `0 / 1 / 2` に見立てた**三進法（9の位 → 3の位 → 1の位）**で順次点灯・消灯し、パッチ表示に戻る。
  * バンクモード中：選択中のバンクを三進法アニメーション＋小休止で常時ループ表示。
* **ループ設定アニメーション:** プログラムモード中、選択中のループ状態に応じて対応LEDが点滅（ONの時は高速、OFFの時は低速）。
